Chorus — icon set

Original line-icon silhouettes for the Sonos & Symfonisk line, drawn by form factor so any speaker reads at a glance. Monochrome, single-stroke, theme-aware — the same family used on the bonding stage. Not official product art (sandbox blocks external images; and it keeps us clear of licensing).

Each is a self-contained inline <svg> using currentColor, so it inherits text color and scales cleanly. In the integration these map from each player’s reported model string via iconFor(model).
