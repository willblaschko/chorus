## How to sign

Add a `Signed-off-by` line to each commit (the Developer Certificate of Origin
convention), which you can do automatically with `git commit -s`:

```
Signed-off-by: Your Name <your.email@example.com>
```

Including that line in a contribution to this repository indicates your agreement
to this CLA.
